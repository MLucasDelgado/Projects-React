## Descripción

Pequeña aplicación desarrollada con React y TypeScript que replica una tarjeta de seguimiento estilo Twitter/X.  
Incluye renderizado dinámico de usuarios y estilos interactivos para seguir o dejar de seguir perfiles.

## Conceptos practicados

- Componentes reutilizables
- Props
- Renderizado con `.map()`
- Manejo de estado con `useState`
- Estilos dinámicos con CSS
