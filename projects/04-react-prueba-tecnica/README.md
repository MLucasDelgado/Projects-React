# Prueba Técnica React - Junior/Trainee

## Descripción

Aplicación desarrollada con React que consume dos APIs para mostrar hechos aleatorios e imágenes dinámicas de gatos.

La aplicación:

1. Obtiene un hecho aleatorio sobre gatos desde una API.
2. Extrae la primera palabra del hecho obtenido.
3. Muestra una imagen de un gato utilizando esa palabra en una segunda API.

## APIs utilizadas

- Facts Random: `https://catfact.ninja/fact`
- Cat as a Service: `https://cataas.com/cat/says/hello`

## Conceptos practicados

- Consumo de APIs
- Manejo de estado con React
- Uso de `fetch`
- Renderizado dinámico
- Manipulación de strings
- Manejo de efectos con `useEffect`
- Componentes funcionales
