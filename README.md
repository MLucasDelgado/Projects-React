# Convención de Commits

Este proyecto utiliza una convención de commits inspirada en **Conventional Commits** para mantener un historial más ordenado y fácil de entender.

| Tipo | Uso |
|------|------|
| `feat` | Agrega una nueva funcionalidad o característica |
| `fix` | Corrige errores o bugs |
| `style` | Cambios visuales o de estilos sin modificar lógica |
| `docs` | Cambios en documentación |
| `refactor` | Reorganiza o mejora código sin cambiar comportamiento |
| `chore` | Configuración, dependencias o tareas de mantenimiento |

## Ejemplos

```bash
feat: implementa botón follow/unfollow
fix: corrige renderizado de imagen del gato
style: mejora diseño visual de la app
docs: agrega README con descripción del proyecto
refactor: reemplaza cards manuales por renderizado con map
chore: configuración inicial del proyecto
